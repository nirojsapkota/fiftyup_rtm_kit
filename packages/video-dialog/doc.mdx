# VideoDialog

## Basic usage

<Playground>
  <VideoDialog {...videoProps} />
</Playground>

### Video Component with default width and height

<Playground>
  <VideoDialog videoSrc="https://www.youtube.com/embed/_NDxJucqwiQ" description="One Big Switch" />
</Playground>

### Video Component with variable width and height
<Playground>
  <VideoDialog width="180px" height="240px" videoSrc="https://www.youtube.com/embed/_NDxJucqwiQ" description="One Big Switch" />
</Playground>

### Add styles to the video container and/or iframe

# LoginPanel

## Basic usage

Redirect when success login:
<Playground>
  <LoginPanel {...mockData} handleSubmit={loginMock(200, { data: { redirectPath: '/packages/login-panel' } })} />
</Playground>

Raise error for bad request:
<Playground>
  <LoginPanel {...mockData} handleSubmit={loginMock(400, { data: {errors: ['Sign in failed']}})} />
</Playground>

Raise error when internal error:
<Playground>
  <LoginPanel {...mockData} handleSubmit={loginMock(500, { data: {errors: ['Something went wrong']}})} />
</Playground>

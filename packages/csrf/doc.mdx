# Csrf

The Csrf component is responsible for validating input csrf token and generating new csrf token when invalid

## Basic usage

```js
  <Csrf authenticityToken='input_token_string' validateUrl='/csrf/validate' generateTokenUrl='/csrf/generate'>
    {({ authenticityToken }) => (
      <div data-testid="id-token">Hello world!</div>
    )}
  </Csrf>
```

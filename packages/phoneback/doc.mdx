# Phoneback

## Basic usage

In most cases the Phoneback can be used as a dialog popup:

<Playground>
  <Phoneback {...sample} />
</Playground>

With props that supports markdown

<Playground>
  <Phoneback {...markdownSample} />
</Playground>

This package exports a standalone phoneback box:

<Playground>
  <PhonebackBox {...sample} />
</Playground>

The standalone form is exported as well:

<Playground>
  <PhonebackForm {...sample} />
</Playground>

Form errors are shown above the disclaimer, the following form will
throw an error on submission:

<Playground>
  <PhonebackForm
    {...sample}
    form={{...sample.form, onSubmit: async () => 'some error'}}
  />
</Playground>

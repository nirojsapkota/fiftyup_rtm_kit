# Markdown

Markdown is a universally recognised plaintext approach to writing content with styling without allowing the end-user to write html directly.

It supports most of the basic things you'd get out of a WYSIWYG with an inline syntax.

## Headers

```md
### H3 Header
```

Rendered as:

<Markdown raw="### H3 Header" />

## Text styling

```md
You can write _emphasis_ and **bold** text like this.
```

Rendered as:

You can write _emphasis_ and **bold** text like this.

---

## List

```md
You can write list items like 
 - list item 1
 - list item 2
```

Rendered as:

You can write list items like 
- list item 1
- list item 2

---

## Links

```md
Links work [like this](https://example.com 'link title')
```

Rendered as:

Links work [like this](https://example.com)

### Custom tracking on a link

You can track user behaviour like 'get_started' actions by providing an action pipe:

```md
[Click here to get started|get_started](https://example.com 'link title')
```

Rendered as:

[Click here to get started](https://example.com 'link title')

---

## Data interpolation

When provided with a `referenceObject` the Markdown component supports dynamic values

```md
Your offer is {{offer.discount}}% below the standing offer
```

Rendered as:

Your offer is 15% below the standing offer

### Data Interpolation

In the example below, notice the `referenceObject` provided, the `{{campaign.name}}` is a dot accessor that
will render the word 'undefined' when it can't find a match with the reference object.

<Playground>
  <Markdown
    referenceObject={{
      campaign: {
        name: 'Origin BES',
      },
    }}
    raw="Hello {{campaign.name}} what [this should support sentences|get_started](https://code.com 'My-Link') here?"
  />
</Playground>

## What is markdown?

> NOTE: most markdown features are not yet supported (ex. lists, tables, etc). Find more syntax info [here](https://daringfireball.net/projects/markdown/syntax)

From https://daringfireball.net/projects/markdown/syntax:

> Markdown is intended to be as easy-to-read and easy-to-write as is feasible... Markdown’s syntax is comprised entirely of punctuation characters, which punctuation characters have been carefully chosen so as to look like what they mean. E.g., asterisks around a word actually look like _emphasis_. Markdown lists look like, well, lists. Even blockquotes look like quoted passages of text, assuming you’ve ever used email.

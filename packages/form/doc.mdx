## Basic usage

<Playground>
    <StepForm {...stepInputs} renderForm={formProps => formProps}>
      {({ activeFormId, forms }) => {
        console.log(forms);

          <Accordion

      }}

Since forms can be strung together, it's often useful to pass through some
forms which already have any info they need. Providing `passThru` will ensure
that the form is valid, and if so it will call it's `onSuccess` prop. Note
that it will not submit the form, meaning no API call will be made

<Playground>
  <Form {...presignupInputs} passThru onSuccess={values=> console.log('success', values)} />
</Playground>

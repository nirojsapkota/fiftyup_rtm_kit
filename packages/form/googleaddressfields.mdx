## Autocomplete

#### Address autocomplete using google api

This is the implementation of react-places-autocomplete node package.
For demo purpose, the response from the google is mocked, as GoogleApi requires api key which is charged per usage.
On actual app, we'll need to import the maps script
`searchOptions` -> pass the option to GoogleMaps API https://developers.google.com/maps/documentation/javascript/places-autocomplete

`componentRestrictions` to limit the country to query to reduce the Cost
`minInputLength` to prohibit hitting google's api if the min input length is not provided

# Test Coverage

## False Positives

Sometimes the coverage report will lead you to thinking you have tested every possible scenario.

Given the following component:
```js
// img.js
const borderRadius = props => ({
  circle: "50%",
  rounded: props.theme.borderRadius,
});

const Img = styled.image`
  border-radius: ${props => borderRadius(props)[props.shape] || "0"};
`;
```

And the following test:

```js
// __tests__/test.js
const setup = () => {
  const { container } = render(
    <Img
      src="test-image.jpg"
      shape="circle"
    />
  );

  return container;
};

describe(`<Img />`, () => {
  it(`should have correct src`, () => {
    const imageTag = setup().querySelector(`img`);
    expect(imageTag.getAttribute(`src`)).toEqual(`test-image.jpg`);
  });
});
```

Since the `borderRadius` function executes both lines 3 & 4, it's returning 100% coverage.
If this button wasn't loaded with a styled-components `ThemeProvider`, we would
break the component and the test would still pass with 100% coverage.
